# assets/ — Recursos estáticos

## Qué hay
- `logos/icono.svg`: icono de Genérico (G decorada en grises); sirve de favicon y cambia con el modo claro u oscuro del sistema.
- `logos/logo.svg`: logo horizontal para fondos claros.
- `logos/logo-oscuro.svg`: logo horizontal para fondos oscuros.

## Qué agregar
- `logos/<cliente>/`: logo por tienda (SVG o PNG optimizado).
- `icons/`: iconos propios cuando se reemplacen los embebidos en `src/config/nav.js`.
- `fonts/`: tipografías locales, si se deja de usar la fuente del sistema.
- `plantillas/`: archivo CSV de ejemplo para importar inventario (`inventario-ejemplo.csv`).
