# deploy/ — Despliegue (etapa 6)

## Qué agregar
- `Dockerfile` del backend y del frontend.
- `docker-compose.yml` para correr todo en local (frontend, backend, PostgreSQL).
- `nginx.conf` o `Caddyfile` con HTTPS.
- `.env.example` con las variables necesarias (sin valores reales).
- Guía del servicio elegido (Render, Railway o VPS) y flujo de CI en `.github/workflows/`.
